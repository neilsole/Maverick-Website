# Photos

Drop real photos of the shop in this folder, then follow the swap instructions
in `index.html` (search for `photo-ph` — each placeholder has an HTML comment
right above it showing the exact `<img>` tag to paste in its place).

Use real photos of the actual shop, barbers, and Natick Center storefront.
No stock imagery.

| Filename              | Used for              | Suggested size (px) | Notes                            |
|-----------------------|-----------------------|---------------------|----------------------------------|
| `shop-front.jpg`      | Hero, right side      | 1200 × 1500 (4:5)   | Storefront or a strong interior  |
| `about-interior.jpg`  | About section         | 1000 × 1200 (4:5)   | Chairs, mirrors, the room        |
| `team-daniel.jpg`     | Team — Daniel DaSilva | 700 × 700 (square)  | Head-and-shoulders               |
| `team-greg.jpg`       | Team — Greg           | 700 × 700 (square)  | Head-and-shoulders               |
| `og-image.jpg`        | Link previews (social)| 1200 × 630          | Logo + storefront works well     |

## Tips

- Export as JPG, quality ~80%, aim for under ~400 KB each so pages load fast.
- Keep the aspect ratios above so nothing stretches.
- After adding `og-image.jpg`, the social preview is already wired up in
  `index.html` (`<meta property="og:image">`).
